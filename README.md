# Себяшка — ИИ-стикеры из любого фото в Telegram

Пользователь загружает любое фото — себя, друга, питомца или персонажа, — выбирает стиль, при желании дописывает пожелание текстом и через 1–5 минут получает стикерпак прямо в Telegram. Оплата — Telegram Stars или криптовалюта через @CryptoBot.

Бот в чате только открывает приложение. Все действия делаются в мини-приложении: чёрно-белый минимализм, эффект стекла, анимации, векторные иконки.

## Что внутри

| Часть | Технологии | Где |
|---|---|---|
| Мини-приложение | React 19, Vite, Motion (анимации), Lucide (SVG-иконки), glassmorphism, тёмная и светлая тема | `webapp/` |
| API + бот | Node.js 22, TypeScript, Fastify 5, grammY | `server/src/api`, `server/src/telegram` |
| База данных и очередь | PostgreSQL 16 (очередь задач на `FOR UPDATE SKIP LOCKED`, без Redis) | `server/src/db` |
| Генерация | Подключаемые провайдеры: fal.ai / Replicate / mock (провайдер выбирается позже, см. STRATEGY.md); своя обработка: вырезка фона, обводка, 512 px, ≤ 512 КБ | `server/src/generation` |
| Оплата | Telegram Stars (разовые + подписка Pro), CryptoBot (USDT/TON/BTC…) | `server/src/payments` |
| Инфраструктура | Docker Compose, Caddy (автоматический HTTPS), бэкапы | `Dockerfile`, `docker-compose.yml`, `Caddyfile` |

## Возможности

**Для пользователя**
- Любое фото: человек, питомец, персонаж. Пожелание текстом («в костюме супергероя») с фильтром запрещённого.
- Бесплатный мини-пак из 6 стикеров, полный пак — 16 стикеров.
- 9 стилей, включая «Как на фото» (сохраняет рисовку персонажа); 5 из них премиум.
- Прогресс генерации в реальном времени, предпросмотр, кнопка «Добавить в Telegram».
- Магазин с оплатой через Stars или крипту, подписка Pro.
- Реферальная программа: +1 пак за первую покупку друга.
- Подарочные паки по ссылке.
- Уведомления в бот: пак готов, оплата прошла. Каждое открывает нужный экран приложения.

**Для админа** (подробно — DEPLOY.md, раздел 8)
- **Вкладка «Админ» в мини-приложении:**
  - выручка, пользователи, платящие, паки, Stars, крипта;
  - воронка за 7 дней;
  - последние оплаты;
  - поиск пользователя, начисление паков, бан.
- **Генерация без списания** — для тестов и демо.
- **Алерты в бот:** новые пользователи, счета, оплаты, созданные, готовые и проваленные паки, сбои.
  - события склеиваются, чтобы бот не упёрся в лимиты Telegram;
  - каждый тип включается и выключается кнопками в `/alerts`;
  - можно дублировать алерты в группу.
- **Команды:**
  - `/admin` — сводка;
  - `/user` — карточка пользователя;
  - `/grant <id> <±n>` — начислить или списать паки;
  - `/refund <charge_id>` — возврат Stars;
  - `/ban <id> [off]` — бан.

## Надёжность: что предусмотрено

- **Деньги**
  - Каждое движение кредитов проходит через журнал `ledger` и идемпотентно по ключу. Повторный вебхук или двойной клик не начислит дважды; это проверено тестом с параллельными запросами.
  - Баланс не может уйти в минус: стоят и проверка в коде, и ограничение CHECK в БД.
  - Пак не собрался — кредиты или бесплатная попытка возвращаются автоматически.
  - Сломался ИИ-провайдер (ключ, лимиты) — паки ждут в очереди, деньги не трогаются, админ получает алерт.
  - Вебхук CryptoBot проверяется по HMAC. Если вебхук потерялся, раз в минуту работает поллер.
  - Оплата Stars проверяется в `pre_checkout_query`: владелец, сумма, статус заказа.
- **Telegram**
  - Подпись initData мини-приложения проверяется на каждом запросе.
  - На ошибку 429 (flood) — повтор после паузы.
  - Если набор стикеров создан наполовину — догрузка без дублей.
  - Пользователь не запускал бота — пак ждёт `/start` и догружается сам.
- **Очередь**
  - Воркер упал — задача возвращается в очередь через 15 минут.
  - Уже готовые стикеры повторно не генерируются.
  - Pro-пользователи идут первыми.
- **Антифрод**
  - Бесплатный пак выдаётся один раз.
  - Реферал засчитывается только новому аккаунту, без самоприглашения и циклов.
  - Подарок нельзя активировать самому и нельзя активировать дважды.
  - Запросы ограничены по частоте.
- **Приватность**
  - Селфи удаляются через 24 часа, EXIF и GPS вырезаются.
  - Превью отдаются по подписанным ссылкам.

## Быстрый старт (локально)

```bash
npm install
cp .env.example .env         # BOT_MODE=polling, GEN_PROVIDER=mock, DATABASE_URL=...
npm run dev:server           # :3000 — API + бот
npm run dev:webapp           # :5173 — мини-приложение
# Без ИИ-ключей: GEN_PROVIDER=mock — всё работает на стикерах-заглушках
```

Тесты (51 шт.: подписи, обработка картинок, деньги и гонки, полный цикл генерации, HTTP API, вебхук CryptoBot, оплата Stars, админка, алерты, маршрутизация бота):
```bash
TEST_DATABASE_URL=postgres://user:pass@localhost:5432/test npm test
```

Прод: см. **[DEPLOY.md](DEPLOY.md)**.

## Структура

```
server/src/
  config.ts              — все настройки и проверка .env
  domain/catalog.ts      — стили, эмоции, цены (менять цены — здесь)
  domain/users.ts        — пользователи, кредиты, рефералы
  domain/orders.ts       — заказы, зачисление оплат, подарки, возвраты
  domain/packs.ts        — паки и очередь
  generation/            — провайдеры ИИ, обработка стикеров, пайплайн воркера
  payments/              — Stars и CryptoBot
  telegram/              — бот, initData, загрузка стикерпаков
  api/server.ts          — HTTP API, вебхуки, раздача мини-приложения
  admin/                 — алерты админам и статистика
webapp/src/
  screens/               — Главная, Создание, Пак, Магазин, Профиль, Админ
  art.tsx                — SVG-иллюстрации
  ui.tsx, styles.css     — дизайн-система (стекло, кнопки, анимации)
```
