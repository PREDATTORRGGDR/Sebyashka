# Деплой «Себяшки» на прод — пошагово

Инструкция от «ничего нет» до «бот принимает деньги». Время: 1–2 часа. Команды копируй как есть.

**Что получится в итоге:**

```
Пользователь ─► Telegram ─► https://твой-домен ─► Caddy (HTTPS, Let's Encrypt)
                                                    │
                                   ┌────────────────┴───────────────┐
                                   ▼                                ▼
                         app: API + бот + мини-апп        worker: генерация стикеров
                                   │                                │
                                   └──────────► PostgreSQL ◄────────┘
                                   ▲
            @CryptoBot ── webhook ─┘      fal.ai ◄── worker (ИИ-генерация)
```

---

## 0. Что понадобится и сколько стоит

| Что | Где | Цена |
|---|---|---|
| Домен | Namecheap, Porkbun, Cloudflare Registrar | $2–12/год |
| VPS 2 vCPU / 4 GB RAM / 40 GB | Hetzner (CX22), DigitalOcean, Vultr | $5–12/мес |
| Telegram-бот | @BotFather | бесплатно |
| Оплата Stars | встроена в Telegram | 0 ₽ за подключение |
| Оплата криптой | @CryptoBot → Crypto Pay | комиссия ~1% с платежа |
| ИИ-генерация | fal.ai | ~$0.02–0.04 за стикер (см. [docs/ECONOMICS.md](docs/ECONOMICS.md)) |
| TON-кошелёк для вывода Stars | Tonkeeper / Telegram Wallet | бесплатно |

> Сервер лучше брать в Европе (Германия, Финляндия, Нидерланды): быстрый доступ к API Telegram и fal.ai.

## 1. Домен и DNS

1. Купи домен, например `sebyashka.app`. Можно использовать поддомен существующего: `stickers.твойдомен.com`.
2. В DNS-панели создай **A-запись**:
   - Имя: `@` (или `stickers` для поддомена)
   - Значение: IP твоего VPS (появится на шаге 2)
   - TTL: 300
3. Если DNS на Cloudflare — поставь **серое облако (DNS only)**. С оранжевым облаком Caddy не сможет выпустить сертификат.
   Если очень нужен прокси Cloudflare — сначала получи сертификат с серым облаком, потом включи оранжевое и режим SSL **Full (strict)**.

Проверка (через 1–10 минут после изменения):
```bash
dig +short stickers.твойдомен.com   # должен вернуть IP сервера
```

## 2. Сервер

### 2.1. Создай VPS
- ОС: **Ubuntu 24.04 LTS**
- Добавь свой SSH-ключ при создании (`ssh-keygen -t ed25519`, если ключа нет)
- Запиши IP → пропиши его в A-запись из шага 1

### 2.2. Базовая защита
```bash
ssh root@IP_СЕРВЕРА

# обновления
apt update && apt upgrade -y
apt install -y ufw fail2ban unattended-upgrades git
dpkg-reconfigure -plow unattended-upgrades   # ответь Yes

# файрвол: только SSH, HTTP, HTTPS
ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 443/udp
ufw --force enable

# swap на 2 ГБ — страховка от нехватки памяти при сборке
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

### 2.3. Docker
```bash
curl -fsSL https://get.docker.com | sh
docker --version && docker compose version
```

## 3. Бот в @BotFather

1. `/newbot` → имя: `Себяшка — стикеры из фото` → username: например `sebyashka_bot` (должен заканчиваться на `bot`).
2. Сохрани **токен**, он пойдёт в `BOT_TOKEN`. Никому его не показывай.
3. Оформление:
   - `/setuserpic`: аватарка 512×512
   - `/setdescription`: «Сделаю стикерпак из любого фото за 2 минуты: ты, друг, питомец или персонаж. 9 стилей и пожелания текстом. Первый пак — бесплатно.»
   - `/setabouttext`: «Стикеры из твоего лица. Открывай приложение 👇»
4. **Мини-приложение**: `/mybots` → твой бот → **Bot Settings → Configure Mini App → Enable Mini App** → URL: `https://твой-домен`.
   После этого работают ссылки вида `t.me/sebyashka_bot?startapp=...`, а бот может попасть в каталог приложений Telegram.
5. **Кнопка меню** (синяя кнопка слева от поля ввода) ставится автоматически при старте сервера. Вручную: `Bot Settings → Menu Button → Configure` с тем же URL.
6. `Bot Settings → Allow Groups` → **Turn off**: бот работает только в личке.
7. **Оплата Stars** не требует настройки и провайдера. От бота Telegram требует две вещи, и в коде они уже есть:
   - команда `/paysupport` для вопросов по оплате;
   - команда `/terms` с условиями.

Узнай свой Telegram ID у @userinfobot. Он пойдёт в `ADMIN_IDS`, чтобы тебе были доступны `/stats`, `/grant`, `/refund`, `/ban` и `/user`.

## 4. Приём криптовалюты — @CryptoBot (Crypto Pay)

1. Открой @CryptoBot → **Crypto Pay** → **Create App** → назови `Sebyashka`.
2. Скопируй **API Token**, он пойдёт в `CRYPTOBOT_TOKEN`.
3. В том же приложении: **Webhooks → Enable** → URL:
   ```
   https://твой-домен/cryptobot/webhook
   ```
4. Проверка без реальных денег: сделай то же в **@CryptoTestnetBot** и поставь `CRYPTOBOT_NETWORK=testnet`. Тестовые монеты выдаются бесплатно. После проверки переключись на mainnet-токен и `CRYPTOBOT_NETWORK=mainnet`.

Как устроена надёжность:
- **Вебхук проверяется по подписи** (HMAC-SHA256). Подделать оплату нельзя.
- **Вебхук потеряется?** Раз в минуту сервер сам сверяет неоплаченные счета через `getInvoices`, и деньги всё равно зачислятся.
- **Пользователь вернулся раньше вебхука?** Мини-приложение само спрашивает статус, сервер проверяет счёт в CryptoBot.
- **Повторный вебхук?** Двойного зачисления не будет: у каждого платежа уникальный id.

## 5. ИИ-генерация (провайдер выбирается позже)

Сейчас стоит `GEN_PROVIDER=mock`. Так весь сервис можно запустить и проверить (оплаты, паки, админку) без ИИ: вместо генерации получаются стикеры-заглушки.

Когда выберешь модель по [docs/STRATEGY.md](docs/STRATEGY.md) (там сравнение цен и окупаемости fal, Gemini, GPT-Image и своего GPU):

**fal.ai**
1. Зарегистрируйся на https://fal.ai → **Billing**, пополни баланс на $10–20.
2. **Keys → Create key**.
3. В `.env` пропиши:
   ```env
   GEN_PROVIDER=fal
   FAL_KEY=ключ
   FAL_MODEL=модель
   ```
4. Сверь поля модели на её странице (**API → Schema**). Если они отличаются от шаблона по умолчанию, задай `FAL_INPUT_TEMPLATE`. Примеры есть в STRATEGY.md §1.2.

**Replicate**
```env
GEN_PROVIDER=replicate
REPLICATE_TOKEN=токен
REPLICATE_MODEL=owner/model
REPLICATE_INPUT_TEMPLATE=шаблон
```

**Другой провайдер** (например, OpenAI GPT-Image) — это один новый класс в `server/src/generation/providers.ts` по образцу существующих. Пайплайн уже передаёт уровень пака (`free` / `paid` / `premium`), чтобы качество можно было выбирать под экономику.

**Удаление фона**
- `BG_REMOVAL=local` — бесплатно, работает по белому фону.
- `BG_REMOVAL=fal` — нейросеть, точнее, примерно +$0.002 за стикер.

Если ключ неверный или у провайдера закончились деньги, паки **не проваливаются**: они ждут в очереди, а админ получает алерт. После пополнения очередь продолжит работу сама.

## 6. Запуск

```bash
# на сервере
cd /opt
git clone https://github.com/predattorrggdr/idn.git sebyashka
cd sebyashka
cp .env.example .env
```

Сгенерируй секреты:
```bash
echo "POSTGRES_PASSWORD=$(openssl rand -hex 24)"
echo "SIGNING_SECRET=$(openssl rand -hex 32)"
echo "TELEGRAM_WEBHOOK_SECRET=$(openssl rand -hex 32)"
```

Открой `.env` (`nano .env`) и заполни:

| Переменная | Значение |
|---|---|
| `DOMAIN` | `stickers.твойдомен.com` |
| `PUBLIC_URL` | `https://stickers.твойдомен.com` |
| `ACME_EMAIL` | твоя почта |
| `BOT_TOKEN` | из BotFather |
| `BOT_USERNAME` | username бота без @ |
| `BOT_MODE` | `webhook` |
| `TELEGRAM_WEBHOOK_SECRET` | сгенерированный выше |
| `ADMIN_IDS` | твой Telegram ID |
| `SUPPORT_USERNAME` | аккаунт поддержки без @ |
| `POSTGRES_PASSWORD` | сгенерированный выше |
| `SIGNING_SECRET` | сгенерированный выше |
| `CRYPTOBOT_TOKEN` | из Crypto Pay |
| `GEN_PROVIDER` | `mock` для первого прогона, потом выбранный провайдер |

Запуск:
```bash
docker compose up -d --build
docker compose ps                     # все сервисы должны быть Up (healthy)
docker compose logs -f app worker     # логи; выход — Ctrl+C
curl https://stickers.твойдомен.com/health   # {"ok":true}
```

При первом старте происходит следующее:
- применяются миграции БД;
- Telegram получает адрес вебхука;
- ставятся меню команд и кнопка мини-приложения;
- Caddy выпускает HTTPS-сертификат (до минуты).

## 7. Проверка на проде (обязательно перед рекламой)

- [ ] `/start` в боте → приветствие с кнопкой «Открыть Себяшку»
- [ ] Мини-приложение открывается, в шапке виден баланс
- [ ] Загрузка фото → выбор стиля + пожелание → **бесплатный мини-пак** собирается за 1–3 минуты
- [ ] Админу приходят алерты: новый пользователь, пак создан, пак готов
- [ ] Приходит сообщение «Стикерпак готов», по кнопке открывается пак, «Добавить в Telegram» работает
- [ ] **Stars:** купи «1 пак» за 250⭐ → баланс +1 → потом `/refund <charge_id>` вернёт звёзды (charge_id есть в `/user <id>` или в логах)
- [ ] **Crypto:** на testnet оплати пак → баланс +1 → вернись на mainnet
- [ ] Реферальная ссылка из профиля: второй аккаунт → покупка → первому +1 пак
- [ ] Подарок: купить «Подарить пак» → ссылка → второй аккаунт получает пак
- [ ] Вкладка «Админ» открывается только у админов, `/alerts` переключает уведомления

## 8. Админ: права и алерты

Админ — это любой Telegram ID из `ADMIN_IDS`. Что он получает:

- **Вкладка «Админ» в мини-приложении:**
  - выручка (всего и за сутки), пользователи, платящие, паки, Stars к выводу, крипта;
  - воронка за 7 дней;
  - последние оплаты;
  - поиск пользователя по ID, @username или имени, начисление и списание паков, бан.
- **Бесплатная генерация:** полный пак в любом стиле без списания. Нужно для тестов и демо.
- **Алерты в бот** о событиях:

  | Алерт | Когда приходит |
  |---|---|
  | 👤 Новый пользователь | с источником: органика, реф-ссылка, подарок, метка |
  | 🧾 Счёт | пользователь нажал «купить» |
  | 💰 Оплата | с суммой, балансом и начислением рефереру |
  | 🎨 Новый пак | стиль, бесплатный или платный, пожелание |
  | ✅ Пак готов | время сборки и ссылка на набор |
  | ⚠️ Пак провален | причина |
  | 🚨 Системный сбой | провайдер ИИ, незачисленная оплата |

  События склеиваются в одно сообщение раз в 3 секунды, поэтому бот не упирается в лимиты Telegram даже при наплыве.
- **`/alerts`** — кнопки включить или выключить каждый тип (у каждого админа свои). Системные алерты приходят всегда.
- **`ADMIN_CHAT_ID`** — дополнительно слать алерты в группу, например команде. Бота нужно добавить в эту группу.
- **Команды в боте:**
  - `/admin` — сводка;
  - `/user <id|@username>` — карточка пользователя со списком charge_id;
  - `/grant <id> <±n>` — начислить или списать паки;
  - `/refund <charge_id>` — возврат Stars;
  - `/ban <id> [off]` — бан.

## 9. Как вывести деньги

### Telegram Stars → TON → деньги
1. Stars копятся на балансе бота. Посмотреть: профиль бота в Telegram → **Изменить → Баланс / Stars** (путь зависит от версии клиента) или `/stats` в боте.
2. **Вывод доступен через 21 день** после каждого платежа, минимум **1000 ⭐**.
3. Нажми **Вывести через Fragment** → войди через Telegram → пройди **KYC** (документ и селфи, один раз) → подключи TON-кошелёк (Tonkeeper) → получи TON. Курс для разработчика около **$0.013 за 1 ⭐**.
4. TON → USDT или фиат через биржу или P2P.

### CryptoBot
Оплаты копятся в балансе приложения Crypto Pay. Их можно перевести на свой кошелёк @CryptoBot (**Crypto Pay → приложение → Balance → Withdraw/Transfer**), а оттуда вывести на внешний кошелёк или биржу.

> Налоги с дохода — по законодательству страны, где ты оформлен. Уточни у бухгалтера, как учитывать доход в криптовалюте.

## 11. Бэкапы (настрой сразу)

Ежедневный дамп БД с хранением 14 дней:
```bash
mkdir -p /opt/backups
cat > /opt/backup.sh <<'EOF'
#!/bin/sh
set -e
cd /opt/sebyashka
docker compose exec -T db pg_dump -U sebyashka -Fc sebyashka > /opt/backups/db-$(date +%F).dump
find /opt/backups -name 'db-*.dump' -mtime +14 -delete
EOF
chmod +x /opt/backup.sh
(crontab -l 2>/dev/null; echo "30 3 * * * /opt/backup.sh") | crontab -
```

Копируй бэкапы за пределы сервера, например `rclone` в Backblaze B2 или S3. Если сервер умрёт вместе с бэкапами, пропадут балансы пользователей.

Восстановление:
```bash
docker compose exec -T db pg_restore -U sebyashka -d sebyashka --clean < /opt/backups/db-2026-10-01.dump
```

Файлы в volume `appdata` (загруженные фото и превью) не критичны. Фото живут 24 часа, а сами стикерпаки хранятся в Telegram.

## 12. Мониторинг

- **UptimeRobot / Better Stack** (бесплатно): проверка `https://домен/health` каждые 5 минут, алерт в Telegram.
- **Вкладка «Админ» и `/admin`:** пользователи, паки, выручка, воронка за 7 дней.
- **Алерты в бот:** о новых пользователях, счетах, оплатах, паках и сбоях (см. раздел 8).
- **Логи:** `docker compose logs --since 1h app worker | grep -i error`
- **Место на диске:** `df -h` и `docker system df`. Раз в месяц: `docker system prune -f`.

## 14. Частые проблемы

| Симптом | Причина → решение |
|---|---|
| Caddy не выпускает сертификат | DNS ещё не обновился (`dig`), закрыт порт 80 (`ufw status`), оранжевое облако Cloudflare → поставь серое |
| Бот молчит | `docker compose logs app`: неверный `BOT_TOKEN` (сервер не стартует с понятной ошибкой) или не установлен вебхук. Проверка: `curl https://api.telegram.org/bot<TOKEN>/getWebhookInfo` |
| `getWebhookInfo` → `last_error_message: 401` | `TELEGRAM_WEBHOOK_SECRET` поменялся без перезапуска → `docker compose up -d` |
| Мини-приложение — белый экран | URL в BotFather не совпадает с `PUBLIC_URL` или не https; жёсткое обновление: закрыть и открыть мини-апп |
| «initData устарели» | Приложение открыто больше суток → закрыть и открыть заново |
| Оплата Stars прошла, паков нет | Придёт алерт админу с charge_id. `/grant <id> <n>` вручную или `/refund <charge_id>` |
| Крипта оплачена, паков нет | Подождать 1 минуту (поллер). Проверить вебхук в Crypto Pay и `CRYPTOBOT_NETWORK` (testnet ≠ mainnet) |
| «Генерация остановлена: HTTP 401/402» | Неверный `FAL_KEY` или кончились деньги на fal.ai → пополнить, очередь продолжится сама |
| Алерты не приходят | Админ не нажимал /start в боте (Telegram не даёт писать первым); для группы — бот не добавлен |
| Пак висит в «Один шаг» | Пользователь не нажимал Start в боте. После `/start` пак догрузится сам |
| Стикеры с белыми краями / без фона | Фон не белый у модели → `BG_REMOVAL=fal` |
| `No space left on device` | `docker system prune -af`, проверить `/opt/backups` |
| Сервер не стартует: «Ошибка конфигурации (.env)» | В сообщении перечислены переменные с ошибками — исправь их |

## 15. Локальная разработка

```bash
# Postgres локально (или docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=dev postgres:16)
npm install
cp .env.example .env    # BOT_MODE=polling, GEN_PROVIDER=mock, DATABASE_URL=postgres://...@localhost/...
npm run dev:server      # API + бот (long polling) на :3000
npm run dev:webapp      # мини-апп на :5173 с прокси на :3000
```

- **Открыть мини-апп в обычном браузере без Telegram:** `DEV_AUTH=true` в `.env` и `VITE_DEV_USER=12345` при запуске webapp. В production DEV_AUTH запрещён, сервер откажется стартовать.
- **Открыть локальную версию прямо в Telegram:** нужен https-туннель — `cloudflared tunnel --url http://localhost:5173` или `ngrok http 5173`. Этот адрес пропиши в BotFather как URL мини-приложения.

Тесты:
```bash
TEST_DATABASE_URL=postgres://user:pass@localhost:5432/sebyashka_test npm test
```
